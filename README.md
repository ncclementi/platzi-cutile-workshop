# platzi-cutile-workshop

cuTile Python workshop notebooks for Platzi, run on an
[NVIDIA Brev](https://brev.nvidia.com/) GPU instance managed with
[Pixi](https://pixi.sh/).

- Environment: [`pixi.toml`](pixi.toml)
- Brev instance setup: [`brev/setup_brev.sh`](brev/setup_brev.sh)
- Notebooks: [`notebooks/`](notebooks/)

See [SETUP.md](SETUP.md) for full instructions on provisioning the Brev
instance and running the notebooks.
